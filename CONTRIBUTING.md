# Contributing to Loom

Thank you for your interest in Loom. This is an open, ambitious project and contributions are welcome.

## Getting started

1. Fork the repo
2. Clone your fork
3. Follow the Quick Start in README.md
4. Create a branch: `git checkout -b feature/your-feature`
5. Make your changes
6. Commit: `git commit -m "feat: your feature"`
7. Push and open a PR

## What we need help with

- **Performance** — canvas rendering at scale (100+ nodes)
- **Mobile** — touch UX improvements
- **AI prompts** — better Weaver extraction accuracy
- **Tests** — we have none yet (sorry)
- **Accessibility** — keyboard navigation, screen readers
- **Themes** — new color schemes
- **Integrations** — Slack, GitHub, email

## Code style

- No TypeScript (yet) — plain JS/JSX
- CSS via inline styles using CSS variables
- Keep components focused and small
- Comment anything non-obvious

## Commit format

feat: add something new
fix: fix something broken
chore: maintenance, deps
docs: documentation
style: visual changes
refactor: restructure without behavior change
